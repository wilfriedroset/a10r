# Public copy

a10r is a pet project: one maintainer, spare-time cadence (days,
sometimes weeks per issue or PR), no SLA, no commercial support, no
on-call. Public text matches that framing.

- Write without "we" plurals that imply a team.
- The README attributes the project by its repo URL; the maintainer's
  name stays out.
- Leave out `MAINTAINERS.md`, `GOVERNANCE.md`, `SUPPORT.md`, and
  `FUNDING.yml`; pet-project framing makes them ceremonial.
- No launch announcement; the project is found organically.
- Welcome contributions warmly without drumming up demand the project
  cannot service. The faster path to a feature is a well-tested PR,
  not a feature request.
- a10r is openly built with agentic coding: a human maintainer driving
  an LLM coding agent under a strict TDD loop with per-commit subagent
  review. State it plainly. Name the practice (agentic coding, LLM
  coding agent, AI-assisted), never a specific tool as the project's
  identity; agent-facing docs say "the agent".
- Internal audits, scouting notes, and open-question lists stay out of
  the public tree.
