# Architecture decision records

- **Bar.** Record a decision only when it is hard to reverse AND
  surprising without context AND the result of a real trade-off.
  Domain terms go in [`CONTEXT.md`](../../CONTEXT.md); package layout
  and call flow in [`ARCHITECTURE.md`](../../ARCHITECTURE.md).
- **Format.** Mattpocock grill-with-docs: a terse body of 1-3
  sentences; add Status, Considered Options, or Consequences sections
  only when they earn their keep.
- **File.** `docs/adr/NNNN-slug.md`, numbered one above the highest.
