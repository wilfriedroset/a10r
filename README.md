# a10r

[![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)](LICENSE)

A modern, fast, intuitive TUI for [Prometheus Alertmanager][am] and
[Grafana Mimir][mimir], inspired by [k9s][k9s].

> **Status: pre-v0.1 — under active development.** End-user
> documentation lands when the first usable release ships.

- End-user docs (added before v0.1): [`docs/end-users/`](docs/end-users/)
