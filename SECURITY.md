# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities through GitHub's [Private
Vulnerability Reporting][pvr]: open the **Security** tab on this
repository and click **Report a vulnerability**. This keeps the
report private until a fix is ready.

If you cannot use Private Vulnerability Reporting, email
a10r@duck.com instead. There is no PGP key.

Please do not open a public issue for a security report.

a10r is a spare-time project, so response and disclosure timelines
are best-effort, not guaranteed. Only the latest release is
supported.

[pvr]: https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability
